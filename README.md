# Daily Scripture API

Lightweight public API featuring daily scriptures for Bible apps and devotional tools.

---

## Quick Start

This API is **free to use** and requires **no authentication or API keys**.

* **Base URL:** `https://dailyscriptureapi.onrender.com`
* **Interactive Docs:** Visit [`/scalar/v1`](https://dailyscriptureapi.onrender.com/scalar/v1) in your browser to test endpoints directly.

> **Note on Render Free Tier:**  
> This API is hosted on Render's free tier. If no requests have been made within 15 minutes, the server will go to sleep. **The first request may take 30–50 seconds to wake up.** Subsequent requests will respond instantly.
